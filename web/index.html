[BAP] Bounded Authority Protocol™

Bound authority.
Prove the exact request.

OAuth 2.0 is an authorization framework for delegated, scoped access. BAP complements it with signed grants and holder proofs binding the method, URI, operation and JCS typed projection of cast_arguments. A grant names operations, resources and a time window. Verification returns cryptographic facts against caller-supplied trust and context. Your host runtime separately applies authorization policy, revocation, and replay checks. Keys stay in your custody.

The family lifecycle

Three protocols, one chain of evidence: what the agent is, what was agreed, what this call may do.

[CAP]
Agree the termsCharter revisions bind ABP release digests (abp_bindings); every receipt records the action’s deployment digest and is signed by both parties
→
[BAP]
Bind each requestIssuer-signed grants and holder proofs bind the method, URI, operation and JCS typed projection of cast_arguments to authority bounds; the host applies authorization policy

Custody boundary

Keys stay in your HSM, KMS, or browser key store. The library signs through a handle and checks the returned signature against its public key.

Issuer-role gate

A holder handle can never mint its own capability: grants require an issuer-role identity resolved atomically, before sign() is even called.

Wrong-key guard

Every signature is verified against the resolved public key before assembly. A misconfigured custodian returns signing_failed. No compact is emitted.

Closed errors

A closed error-code set; no key material, nonce values, or report content ever appears in an error.

Suite-specific key setup

Ed25519 and P-256 have distinct public-key formats. Every custody method may be async.

npm install @bounded-authority-protocol/signer@2.0.1 @bounded-authority-protocol/verifier@2.0.1

Contract major 1 (also major 2)

import { ed25519KeyHandle } from "@bounded-authority-protocol/signer";
import { BACKEND_ID } from "@bounded-authority-protocol/verifier";
// WebKit for Linux can transiently refuse key generation; retry only OperationError.
async function generatePair(algorithm: Algorithm | EcKeyGenParams, extractable = false): Promise<CryptoKeyPair> {
  for (let attempt = 0; attempt < 3; attempt++) {
    try { return await crypto.subtle.generateKey(algorithm, extractable, ["sign", "verify"]) as CryptoKeyPair; }
    catch (error) { if ((error as { name?: string }).name !== "OperationError" || attempt === 2) throw error; }
  }
  throw new Error("key generation failed");
}

const pair = await generatePair({ name: "Ed25519" });
const made = await ed25519KeyHandle(pair, { keyId: "example-key", role: "issuer" });
if (!made.ok) throw new Error(made.error);
if ((await made.value.publicKey()).length !== 32 || BACKEND_ID !== "portable") throw new Error("suite setup");
console.log("suite 1: 32-byte public key ready");
